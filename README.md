# Crimson Petal Developer Toolkit

A collection of developer tools and plugin systems designed to speed up development in RPG Maker MZ.

These tools simplify common systems and reduce repetitive eventing work.

## Included Systems

• Smart Door System  
• Smart Chest System  
• Interaction Prompt System  
• Event Template Copier  
• Event Defaults System
